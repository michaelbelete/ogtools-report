# FoodieClub Momentum Report

A premium, high-fidelity dashboard for tracking the momentum of the FoodieClub Pilot program. 

## About
This report focuses on the qualitative and quantitative shifts during Week 1 of the FoodieClub Pilot. It tracks key metrics like Search Visibility, Conversation Shifts, and overall Sentiment Direction to provide a clear, operator-focused view of progress.

The interface is built with React and Tailwind CSS, featuring a borderless, minimal aesthetic with sophisticated typography and depth to reflect a "hire-level" taste.

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd ogtools-report
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

The application will be available at `http://localhost:5173`.

## Tech Stack
- **Framework:** React
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **Typography:** Inter / Sans-serif
- **Palette:** Zinc / Royal Blue (#2563eb)
